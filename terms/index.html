Read the backup checker terms

Sentinel verifies backups but does not make them. Keep originals until you independently test a restore.

The service

Photo Backup Sentinel compares selected media files using content hashes. It also opens a sample from matched backup files.

A hash match shows identical bytes at check time. A sampled read is not a playback or future restore guarantee.

Your responsibility

Choose separate source and backup folders. Maintain independent copies and safely eject storage.

Restore representative files regularly. Do not delete originals based only on a Sentinel result.
