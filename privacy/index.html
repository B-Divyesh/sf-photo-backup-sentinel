Privacy,
plainly.

Your media stays on your device. Photo Backup Sentinel has no server for photos, videos, EXIF, location data, filenames, hashes, or check history.

What the app reads

When you choose folders, the browser grants temporary read access to those local files. The app reads supported media to calculate SHA-256 fingerprints and opens small edge samples of selected backup files. It does not change, copy, or upload those files. Folder access normally ends when the tab closes.

What is stored locally

IndexedDB stores up to three free-edition checks or 30 Pro checks. A check contains folder labels, filenames, relative paths, sizes, modified dates, SHA-256 hashes, and outcomes. Media bytes and EXIF/location fields are not stored. Your browser controls this storage; clearing site data removes it. JSON export and import let you control your records.

Licenses and network access

If you buy or restore Sentinel Pro, a license token and cached verification result are stored in localStorage. The token is sent to the Sociobot billing API no more than once per day for verification. Checkout is hosted by Sociobot/Dodo, the merchant of record, under its own transaction privacy terms.

Tracking

There are no advertising trackers, analytics SDKs, cookies, third-party fonts, or runtime CDN scripts in the app. Service-worker requests fetch only this app’s own files. We may use aggregate server request counts maintained by the host; they contain no media data.

Your choices

Export your report before clearing browser site data if you want to retain it. You can use the complete checking workflow without an account. For privacy questions, contact privacy@sociobot.in.
